# 📌 Ratiba Task Management App

**Ratiba** is a **full-stack task management web app** that allows users to manage their workflow with **boards, tasks, and sub-tasks**. 

## 🔧 Built With

### 🛠 Frontend

- ⚛️ **React.js**
- 💅 **Chakra UI** (for styling)
- 💾 **Zustand** (State Management)

### 🛠 Backend

- 🌐 **Node.js & Express**
- 🗄️ **Mongoose** (MongoDB)
- 🔗 **GraphQL** (API)

## ✨ Features

✔️ **CRUD operations** for boards, tasks, and sub-tasks  
✔️ **User-friendly UX** with smooth interactions  
✔️ **Responsive design** – optimized for both mobile and desktop 📱💻  
✔️ **Google Fonts** for a sleek UI  
✔️ **Inspired by** [this frontend challenge](https://www.frontendmentor.io/challenges/kanban-task-management-web-app-wgQLt-HlbB)
